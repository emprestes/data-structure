# Arrays

## Origem
Estrutura sequencial base da maioria das linguagens e runtimes, derivada de memória contígua indexada.

## Como funciona
Armazena elementos em posições contíguas, acessadas por índice.

## Problemas que resolve
- Acesso direto rápido por posição
- Base para vetores dinâmicos, heaps e tabelas

## Big O
- Acesso por índice: `O(1)`
- Busca linear: `O(n)`
- Inserção/remoção no meio: `O(n)`
- Append em array dinâmico: amortizado `O(1)`
