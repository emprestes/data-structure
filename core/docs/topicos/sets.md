# Sets

## Origem
Derivados da teoria de conjuntos matemática, aplicados em computação para unicidade e operações de pertinência.

## Como funciona
Armazena elementos únicos, geralmente suportando inserção, remoção e teste de existência.

## Problemas que resolve
- Deduplicação
- Interseção/união/diferença
- Controle rápido de "visitado" em algoritmos

## Big O
- Hash set: média `O(1)` para add/remove/contains
- Tree set balanceado: `O(log n)`
