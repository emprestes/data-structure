# Linked Lists

## Origem
Listas encadeadas foram criadas para superar limitações de arrays em inserções/remoções frequentes.

## Como funciona
Cada nó guarda valor e ponteiro(s) para próximo (e opcionalmente anterior).

## Problemas que resolve
- Inserção/remoção eficiente no início e em posições conhecidas
- Base para filas, pilhas e tabelas hash encadeadas

## Big O
- Inserção/remoção na cabeça: `O(1)`
- Busca por valor: `O(n)`
- Acesso por índice: `O(n)`
