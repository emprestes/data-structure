# Binary Trees

## Origem
Árvores binárias foram propostas para organizar dados hierárquicos e viabilizar busca ordenada.

## Como funciona
Cada nó possui no máximo dois filhos (esquerda/direita). Em BST, esquerda < nó < direita.

## Problemas que resolve
- Busca, inserção e remoção ordenadas
- Modelagem de hierarquias
- Base para heaps, AVL, Red-Black

## Big O
- BST balanceada: busca/inserção/remoção `O(log n)`
- BST degenerada: `O(n)`
- Percursos (in/pre/post-order): `O(n)`
